Academic Wizard - Tutoring Booking System
Overview
A growing academic skills and tutoring company offering online and in- person tutoring services. Specializing in helping students aged 10-18 improve their study skills, exam preparation, and subject-specific knowledge (Maths, English, Science). Built using Python (Flask) for the backend/frontend and MySQL (TiDB Cloud) for the database.

Prerequisites
Python 3.x
Internet connection (for Cloud Database access)
Installation & Setup (For Markers)
Navigate to the project folder in the terminal: cd server

Create a virtual environment: python -m venv venv

Activate the environment:

Windows:
venv\Scripts\activate

Mac/Linux:
source venv/bin/activate

Install dependencies: pip install -r requirements.txt

How to Run
Ensure the virtual environment is active.
Run the application: python app.py
Open your browser and visit: http://127.0.0.1:5000
Architecture
Frontend: HTML5, CSS3, Jinja2 Templates
Backend: Python Flask
Database: TiDB Cloud (MySQL compatible)
ORM: SQLAlchemy
